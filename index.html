Control facial para micro:bit

La cámara detecta tu cara y envía 10 veces por segundo los gestos al micro:bit por Bluetooth o por cable USB.

Funciona en Chrome o Edge (ordenador o Android). Las imágenes no salen de tu dispositivo.

Valores de la cara

    Mensaje enviado

    0000000000000000000

    Cámara

    Envío cada 100 ms
    ¿Cómo leer los datos en MakeCode?

    Cada mensaje tiene 19 cifras seguidas de un salto de línea:

    PosiciónDatoRango
    0-1X (horizontal)0-99
    2-3Y (vertical)0-99
    4-5Distancia0-99
    6-7Giro (yaw)0-99
    8-9Inclinación (pitch)0-99
    10-11Boca abierta0-99
    12-13Ojo izquierdo0-99
    14-15Ojo derecho0-99
    16Ladeo (roll)0-9
    17Sonrisa / beso0-9
    18Cara visible0-1

    Es el mismo formato que la app de LOFI Robot (versión 2), así que sus programas funcionan igual. Ejemplo para la cabeza robot por cable USB: servo de la cabeza en P1 (giro) y servo de la boca en P0. Pégalo en la pestaña JavaScript de MakeCode y vuelve a Bloques:

    let datos = ""
let giro = 50
let boca = 0
let visible = 0
serial.setBaudRate(BaudRate.BaudRate115200)
basic.showIcon(IconNames.Square)

serial.onDataReceived(serial.delimiters(Delimiters.NewLine), function () {
    datos = serial.readUntil(serial.delimiters(Delimiters.NewLine))
    if (datos.length >= 19) {
        giro = parseFloat(datos.substr(6, 2))
        boca = parseFloat(datos.substr(10, 2))
        visible = parseFloat(datos.substr(18, 1))
    }
})

basic.forever(function () {
    if (visible == 1) {
        led.plotBarGraph(giro, 99)
        // Giro de la cara (20-80) → ángulo del servo (0-180)
        pins.servoWritePin(AnalogPin.P1,
            Math.constrain(Math.map(giro, 20, 80, 0, 180), 0, 180))
        // Boca (0-50) → servo de 90 (cerrada) a 150 (abierta)
        pins.servoWritePin(AnalogPin.P0,
            Math.constrain(Math.map(boca, 0, 50, 90, 150), 90, 150))
    } else {
        basic.showIcon(IconNames.Asleep, 0)
    }
})

    Si la cabeza gira al revés, cambia 0, 180 por 180, 0. Los números 20-80 y 0-50 se pueden ajustar mirando las barras de esta app.

    Por Bluetooth: añade la extensión bluetooth, pon bluetooth.startUartService() al inicio y cambia serial.onDataReceived y serial.readUntil por bluetooth.onUartDataReceived y bluetooth.uartReadUntil. En Configuración del proyecto elige «No pairing required». No se puede usar a la vez que la extensión radio.

    Del micro:bit a la app: si el micro:bit envía la palabra camera seguida de salto de línea, la app cambia de cámara.
